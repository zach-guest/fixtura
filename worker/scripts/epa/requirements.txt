# Offline EPA ingestion tooling. Nothing here is a frontend or Worker runtime
# dependency -- see AGENTS.md "Architecture and repository map".
#
# Fully pinned, with hashes, so a CI run installs exactly what was tested here
# and a compromised or re-uploaded release cannot substitute itself. Install
# with --require-hashes so pip refuses anything unpinned:
#
#     python3 -m venv .venv
#     ./.venv/bin/pip install --require-hashes -r requirements.txt
#
# Hashes cover the two platforms this pipeline runs on -- local macOS arm64 and
# CI linux x86_64 -- plus the sdist as a fallback. To regenerate after a version
# bump, list the wheels for the new version and take their sha256:
#
#     python3 - <<'PY'
#     import json, urllib.request
#     d = json.load(urllib.request.urlopen("https://pypi.org/pypi/duckdb/<VERSION>/json"))
#     for f in d["urls"]:
#         print(f["filename"], f["digests"]["sha256"])
#     PY
#
